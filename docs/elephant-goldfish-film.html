The elephant remembers.
The goldfish forgets.

How an AI coding session actually thinks: one agent that remembers everything, helper agents that remember nothing, and a vault that outlives them both.

1 / 10Press play.
Your session. Press a button. Try spawning a goldfish, then a fork, and compare what each one knows.

🐘 Elephant

Your main Claude Code session. Every prompt, file and answer piles into its context until it has to compact. It's great at building, but bad at spotting what it forgot to write down.

🐟 Goldfish

A fresh subagent. It knows only its brief, reads only what that brief points to, reports back, then forgets everything. That makes it a good reviewer: if it can't follow your plan, neither can the next developer.

🗄️ Vault

Memory files, CLAUDE.md and vii-brain. The only things that survive into the next session.
